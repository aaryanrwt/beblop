1.	Summary
BEBOP-Gate	is	a	safety	check	that	sits	between	an	AI's	plan	and	the	action.	From	a	camera	clip	it	measures	whether	a	physical
action	fits	(MVP:	a	block	passing	through	a	narrow	gap)	and	returns	
PASS,	FAIL	or	UNDECIDED
.	When	it	cannot	tell,	it	names
the	missing	measurement.	It	never	approves	an	action	only	because	an	AI	model	suggested	it.
Why	now:
	NHTSA's	March	2026	engineering	analysis	of	Tesla	FSD	(EA26002)	centres	on	a	system	failing	to	detect	its	own
degraded	visibility.	Research	preprints	from	2026	(VAP-TAMP,	AsgardBench)	report	that	VLM-based	planners	handle	occlusion
and	state	tracking	poorly.	Broader	recovery	loops	already	exist	(VAP-TAMP),	so	the	product	is	scoped	to	the	part	that	appears
under-served:	
abstaining	with	a	measured	margin
.	This	is	
[UNPROVEN]
	until	our	benchmark	runs.

Primary	user:
	a	robotics	or	computer-vision	developer	who	needs	to	know	why	a	camera-driven	system	said	"go".	
Secondary:
a	hackathon	judge	or	mentor	who	needs	to	see,	in	two	minutes,	that	it	works	and	how	it	fails.

	fail	closed.	Any	missing	input	(no	marker,	no	mask,	API	error)	yields	UNDECIDED,	never	PASS.

	use	only	non-sensitive	footage	if	using	Contributor	mode,	which	lets	Meta	train	on	your	content.

3.	Algorithms
3.1	Pixels	to	millimetres.
	Detect	an	ArUco	marker	of	known	size	with	OpenCV;	scale	=	marker_mm	/	marker_px.	If	the	marker
is	not	found,	the	scene	is	UNDECIDED.
3.2	Masks.
	For	each	of	3	frames	and	5	prompt	variants	per	object	("wooden	block",	"block",	"small	box"	...)	call	SAM;	keep	the
highest-confidence	match.	If	there	are	zero	matches	or	conflicting	multiple	matches,	record	an	instability	flag.
3.3	Gap	and	width.
	Convert	masks	to	polygons	(
cv2.findContours
).	Gap	=	Shapely	distance	between	the	two	obstacle	polygons.
Object	width	=	short	side	of	the	minimum-area	rectangle	of	the	object	mask.	Each	sample	gives	a	value;	the	mean	is	the
estimate	and	sigma	combines	the	sample	standard	deviation	with	a	pixel-quantisation	term	(about	0.5	px)	and	the	marker-scale
error.
3.4	Verdict.
	Let	required	=	width	+	margin	and	d	=	gap	-	required,	with	sigma_d	=	sqrt(sigma_gap^2	+	sigma_width^2).

6.	Evaluation	protocol
~40	scenes:	3	gap	classes	(clear	pass,	marginal,	clear	fail)	x	conditions	(clean,	hand-occluded,	blur,	low	light,	lookalike
distractor,	object	moved	mid-clip).	At	least	10	are	unanswerable	by	design.
Ground	truth:	calipers	or	ruler,	3	repeated	measurements	per	gap.
Split:
	about	12	scenes	for	calibration	(k,	tau,	prompts),	about	28	held	out	for	the	reported	test.	Never	tune	on	the	test	set.
Baselines:	(1)	Muse	Spark	yes/no;	(2)	SAM	mask	+	geometry,	single	shot,	binary;	(3)	VAP-style	reimplementation	(5
paraphrases,	majority	vote,	sufficiency	check,	forced	binary	answer).	Label	(3)	a	reimplementation.
Report	all	numbers	from	the	stored	run;	no	hand-edited	results.
7.	Testing
pytest	unit	tests	for	each	pure	function;	a	fixture	of	5	synthetic	images	with	known	gaps	(drawn	in	OpenCV)	so	geometry	and
verdict	are	tested	without	the	API;	fault-injection	tests	(no	marker,	empty	mask,	API	timeout)	must	all	return	UNDECIDED.
8.	Security	and	operations
API	key	in	an	environment	variable,	never	committed.	Cache	raw	API	responses	to	avoid	repeat	cost.	Avoid	Contributor	mode	for
private	footage.	Log	every	verdict	with	its	inputs	for	audit.
9.	Known	limitations
Planar-scene	assumption	(camera	near	top-down,	marker	on	the	same	plane);	single	object	type;	no	motion	planning;	thresholds
tuned	on	a	small	calibration	set;	SAM	3.1	output	format	and	access	not	yet	verified	by	us.

1.	Principle
The	model	proposes,	the	measurement	decides.
	Foundation	models	find	things	in	images	and	write	explanations.	A	small
deterministic	core	turns	measurements	into	a	verdict.	An	AI	model's	suggestion	is	never	evidence	that	an	action	is	safe.	Any
missing	or	unstable	input	makes	the	system	fail	closed	(UNDECIDED).

4.	Footage	capture	guide	(the	dataset	that	matters)
Rig:
	fixed	phone	on	a	tripod,	near	top-down,	1080p,	30	fps;	printed	ArUco	marker	of	known	size	on	the	same	plane.
Objects:
	one	block	of	known	width;	two	obstacles	forming	a	gap	you	can	adjust.
Gap	classes:
	clear	pass	(about	+30	mm),	marginal	(about	+/-8	mm),	clear	fail	(about	-30	mm).
Conditions	per	class:
	clean;	hand	occluding	one	edge;	blur;	low	light;	lookalike	distractor;	obstacle	moved	mid-clip.
Unanswerable	scenes	(at	least	10):
	deciding	edge	fully	hidden,	or	gap	within	measurement	error.	Correct	output:
UNDECIDED.

	calipers	or	ruler,	3	measurements	per	gap,	stored	in	
truth.csv
	with	the	camera	setup.
