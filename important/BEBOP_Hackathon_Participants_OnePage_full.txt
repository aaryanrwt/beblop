3. What this means for BEBOP
The 'models propose, deterministic code decides' idea is common here, and BONISA already abstains on weak evidence in another
domain. A repo claiming novelty on that alone will lose. BEBOP's defensible edge is narrower: a measured, head-to-head false-approval
benchmark on scenes where the evidence is truly insufficient, with the three baselines. Read BONISA and SceneProof before you
present.
4. Limits of this list
GitHub search finds only public repos that mention the event in the name, description or README, so it misses private repos and
participants with no repo. 'Last pushed' is the most recent push, not the first, so a repo shown on Nov 3 may have started earlier. A repo
existing does not mean a submission was made, and some matches may be unrelated to the hackathon.
